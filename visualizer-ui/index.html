新手操作指南

画布操作

  • 滚轮：缩放画布；按住空白处拖拽：平移画布；拖拽节点：调整位置（自动记住）
  • 双击节点：打开右侧详情抽屉，可查看和编辑该实体
  • 双击画布空白：新建实体
  • 右键空白：新建实体；右键节点：查看详情 / 消亡实体；右键连线：闭合关系
  • 左键点击连线可选中它，按 Delete 键闭合

顶部工具栏

  • 故事时间：查看某一时刻的世界快照，默认最新时刻
  • 类型过滤：点击彩色标签，显示/隐藏对应类型的实体
  • 搜索：输入关键词回车，命中的实体会高亮并居中
  • 显示已闭合：勾选后显示已消亡的实体、已闭合的关系（灰色虚线）
  • 角色视角：只看某个角色知道的信息，TA 不知道的属性会灰显；选「无」退出
  • 新建关系：点击后依次点两个实体，输入关系名即可
  • 重新布局：清空手动拖过的位置，重新自动排列

详情抽屉（双击节点打开）

  • 基本：查看标识与时间，编辑摘要（失焦自动保存）
  • 属性：增删改实体的属性，点「保存修改」统一提交
  • 关系：查看该实体的所有关系，可闭合
  • 可见性：设置哪些角色知道某条属性
  • 历史：该实体的全部版本与变更时间线

事件链页签

  • 按故事时间从左到右排列，展示每一次世界变更
  • 蓝色描边＝人工编辑产生；灰色描边＝引擎自动产生
  • 点击事件卡片，下方显示完整内容（新增属性 / 失效属性 / 因果来源）
