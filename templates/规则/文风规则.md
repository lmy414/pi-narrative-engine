# 文风规则

**渲染器专用——文风规范 + 参考文风 + 禁止词/敏感词。只注入渲染器。**

---

## 文风规范

| 维度 | 设置 |
|------|------|
| 句子长度 | 长短交替，长句用于环境渲染，短句用于动作和情绪 |
| 段落长度 | 每段 2-5 句，不超过 500 字 |
| 对话风格 | 融入叙述，不直接引用（"她低声说了什么"而非对话原文） |
| 描写密度 | 感官细节优先（触觉、嗅觉、视觉），心理描写适度 |
| 章节节奏 | 张弛有度，每段有留白 |

## 渲染禁止事项
