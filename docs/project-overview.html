🖋️ narrative-engine 项目全景图

叙事引擎，面向小说创作的「世界图 + AI 编排」引擎 ｜ 数据截至 2026-08-01（纯 SDK 架构收敛后）
这是什么？ 一个帮助 AI 写小说的引擎：用「世界图」记录故事里谁是谁、发生过什么、谁知道了什么；用「编排器」让多个 AI 子代理（策划/角色/推理/渲染）像剧组一样协作推进剧情，最后把剧情写成章节正文。已完成从「PI 扩展」到「基于 PI SDK 的独立应用」的转型，PI 扩展入口与旧流水线已整体删除。

         scheduler_dispatch（事件派发）
              ▼
        ┌─ 编排器 Orchestrator ────────────────────────┐
        │ ① planner 子代理：查世界图 → 定检索策略        │
        │ ② 角色子代理 ×N：扮演角色 → 输出行动/心理      │
        │ ③ 可见推理子代理：推理 → 写世界图（状态扩散）   │
        │ ④ 渲染器子代理：读章节 → 写正文                │
        └──────────────────────────────────────────────┘
              ▼
        世界图（world.db）    章节文件（正文）
        角色状态/关系/可见性     正文
