# Narrative Engine 前端 UX 需求文档

> 版本：v1.0 ｜ 2026-08-01
> 定位：本文档只描述**功能、内容、交互、跳转**，不描述视觉形态（配色/字体/组件样式/布局细节由设计师自行设计）
> 前置：后端能力已就绪（HTTP API），前端从 0 重建，Web 形态先行

---

## 1. 产品定位

这是一款辅助 AI 写小说的桌面工具（当前 Web 形态）。它围绕「世界图」工作：世界图记录了故事里谁是谁、发生过什么、谁知道什么。用户在工具里：

1. 管理多个小说项目
2. 以 3D 场景浏览世界图，查看/编辑实体（角色、地点、物品、概念）与关系
3. 通过「创作编排」页用对话驱动 AI 推进剧情：AI 策划 → 角色演绎 → 更新世界图 → 写出章节
4. 回看事件链、调试 AI 运行过程、编辑章节文件、配置模型与规则

## 2. 核心概念（设计需体现的领域术语）

| 概念 | 含义 | 设计要点 |
|---|---|---|
| 项目 | 一部小说的完整目录（世界图 + 章节 + 配置） | 项目是顶层容器，全局只有一个「活跃项目」 |
| 世界图 | 实体（角色/地点/物品/概念）+ 关系（知晓/拥有/位于…）+ 事件 | 主工作对象 |
| storyTime | 时间点（ch001.ev003 格式），世界图状态按时间点切片 | 全局核心筛选维度，处处可选 |
| 实体声明 | 实体在某时刻的状态（属性、事实），可被闭合（失效） | 详情页要表达「历史」概念 |
| 可见性 | 角色知道什么（对声明的 known/unknown） | 推理引擎的核心产物 |
| 事件 | 剧情推进的最小单位，可溯源因果关系 | 事件链是回顾剧情的入口 |
| 编排 | 多 AI 子代理（策划/角色/推理/渲染）协作推进剧情 | 创作页的核心操作 |

## 3. 信息架构与导航

### 3.1 页面地图

```
启动 → 项目管理（无活跃项目时的首页）
            │ 激活项目
            ▼
        工作区（顶部全局导航）
   ┌────────┬────────┬────────┬────────┬────────┐
  世界图    事件链   创作编排   调试     文件     设置
```

工作区 = 激活项目后进入的常驻框架，顶部/侧边为全局导航，切换页面不离开项目上下文。

### 3.2 全局导航（工作区内常驻）

- **页面切换**：世界图 / 事件链 / 创作编排 / 调试 / 文件 / 设置，共 6 个入口，任何页面可直达其他页
- **项目信息**：导航区常驻显示当前活跃项目名称，点击可打开项目下拉菜单（切换项目 / 关闭项目返回项目管理）
- **storyTime 选择器**（核心全局控件）：世界图、事件链、文件等页面顶部可见；显示当前时间点，可打开时间点列表切换，也可输入定位
- **搜索入口**：导航常驻全局搜索（实体/事件/全文），输入即跳转搜索结果

### 3.3 跳转关系（关键路径）

- 项目管理 → 激活 → **世界图**
- 世界图 → 点实体 → **实体详情抽屉**（不离开世界图页）
- 世界图/事件链 → 点事件 → **事件链**（定位到该事件）
- 创作编排 → 计划产生 → 可跳 **世界图** 查看更新（验证结果）
- 文件 → 打开章节 → 回到 **创作编排** 上下文（章节正文来自编排结果）
- 调试 → 任何页面出错时可跳转排查

## 4. 全局交互约定

以下约定适用于所有页面，设计师统一应用：

| 场景 | 约定 |
|---|---|
| 加载 | 页面级骨架屏；列表局部加载用行内 loading；3D 场景加载有过渡态 |
| 空态 | 每个列表/图给出空态文案 + 引导操作（如"尚无事件，去创作编排推进剧情"） |
| 错误 | 统一错误提示组件（展示后端错误码 + 可读信息）；网络断开有全局提示 |
| 破坏性操作 | 删除文件、覆盖内容、丢弃计划需二次确认；删除操作成功后行内提示 |
| 写操作反馈 | 成功 toast + 数据就地更新；乐观锁冲突（文件被他人修改）弹冲突解决引导 |
| 表单 | 提交前校验；后端校验失败时字段级定位错误 |
| 快捷键 | 保存（Ctrl/Cmd+S）、搜索（Ctrl/Cmd+K）、时间点切换、撤销重做（远期项） |
| 长任务 | 编排、导入、更新等长时间操作：进度可视化 + 可取消/可离开（后台继续） |

## 5. 页面需求

### 5.1 项目管理（登录后首页）

**功能**：
- 扫描并列出本地可发现的小说项目（自动扫描 + 手动输入路径）
- 新建项目（指定目录、名称；若目录为空自动初始化标准模板）
- 激活项目进入工作区
- 管理已打开项目（多开列表本期不做；切换活跃项目走项目菜单）

**内容**：
- 项目列表：名称、路径、元信息（novel.json 摘要）、状态标记（可激活/需迁移/缺文件）
- 新建表单：目录路径（必填）、项目名称（选填，缺省取目录名）
- 已打开项目栏：活跃项目 + 其他打开项

**交互**：
- 列表项操作：激活（主操作）、打开所在文件夹、迁移（仅需迁移时出现）
- 新建流程：填路径 → 提交 → 成功即自动激活并进入工作区；模板不存在/目录冲突给出明确错误
- 点击「激活」后进入世界图页；无项目时页面提供引导创建

**跳转**：激活 → 世界图；关闭项目 → 回项目管理

---

### 5.2 世界图（主工作台）

**功能**：
- 以 3D 场景浏览全图：节点 = 实体（角色/地点/物品/概念，类型色码区分），连线 = 关系（有方向，可标注类型）
- 查看/编辑单个实体（详情面板）：属性、事实（声明）、关系、可见性
- 按 storyTime 查看世界快照，查看实体在时间轴上的历史演变
- 搜索过滤实体
- 新建/修改关系、更新实体摘要、记录事件（手动补事件）

**内容**（页面分区）：
- 顶部：storyTime 选择器 + 统计（实体数/事件数/当前时间点）
- 左栏：实体列表（类型筛选 + 名称搜索 + 按最近变更排序）
- 主区：3D 场景（节点连线图）
- 右栏/抽屉：实体详情（见 5.3）
- 辅助入口：快速记事件、快速加关系、全局搜索

**交互**：
- 3D 场景：拖拽旋转、滚轮缩放、点选节点高亮并联动详情；连线可点击查看关系详情
- 节点 = 实体的可视化卡片（尺寸、色彩按类型区分；被闭合/死亡的实体视觉标记待实现）
- 选中实体 → 右栏详情；再次点击空白处取消选中
- 切换 storyTime → 全图实体/关系即时切换为对应快照（动画过渡待实现，当前为整体重渲）
- 搜索框输入 → 过滤场景中节点（名称匹配 + 全文检索混合）
- 实体列表项 hover/点击与 3D 场景双向联动
- 手动补事件：表单（事件 ID/类型/涉及实体/故事时间/描述）提交后世界图即时刷新

**跳转**：
- 点实体 → 详情抽屉
- 点事件（详情内事件记录 / 快捷入口）→ 事件链页定位该事件
- 搜索命中实体 → 跳实体；命中章节 → 跳文件页对应章节

---

### 5.3 实体详情（世界图内抽屉/面板）

**功能**：
- 查看实体基本信息：ID、名称、类型、当前摘要
- 编辑摘要（AI 生成的实体摘要人工修正）
- 查看声明历史：每个声明的内容、起始时间、闭合时间、来源（AI 推理/手动）
- 查看关系：出边/入边关系列表（谁指向它、它指向谁），可关闭/新建关系
- 查看可见性：该实体各声明对每个角色的可见状态（哪个角色知道哪条事实）
- 查看事件记录：该实体参与的事件时间线

**内容**：
- 头部：实体名 + 类型徽标 + 摘要文本
- 时间轴：声明/关系随时间的变更列表（storyTime 段展示）
- 关系列表：每条含 对方实体 + 关系标签 + 生效时间段 + 状态（生效/已闭合）
- 可见性表：角色 × 声明的矩阵视图（按需切换声明）

**交互**：
- 摘要：可编辑，保存后即写回
- 声明/关系条目：可查看详情、可手动闭合（二次确认）
- 新建关系：弹表单（对方实体、标签、时间点）
- 历史回放：拖动时间滑块，实体各字段展示对应快照
- 角色矩阵：点击单元格切换 known/unknown

**跳转**：点对方实体 → 切换详情到对方；点事件 → 事件链

---

### 5.4 事件链

**功能**：
- 按时间顺序浏览全部事件
- 单事件因果溯源：向前回溯引发它的原因链，向后看它的影响
- 按实体/类型/关键词筛选事件
- 手动补事件（与世界图页共用能力）

**内容**：
- 主列表：事件时间线（时间点、类型、涉及实体、摘要）
- 详情区：右栏事件详情面板（图形化因果追溯本期不做）
- 筛选栏：实体、事件类型、关键词

**交互**：
- 点击事件 → 展开因果链（向前 N 层 + 向后 N 层）
- 时间线点击 → 同步顶部 storyTime（切换到该事件发生时刻查看世界状态）
- 事件类型色码 + 实体标签可点击过滤
- 因果链节点点击 → 查看该事件详情；双击 → 跳世界图查看该时刻快照

**跳转**：事件 → 世界图（该 storyTime 快照）；涉及实体 → 实体详情

---

### 5.5 创作编排（对话驱动剧情）

**功能**：
- 与 AI 主会话对话（聊天）
- 通过编排器推进剧情：AI 策划检索方案 → 多角色演绎 → 推理更新世界图 → 渲染章节正文
- 计划的确认/丢弃控制（plan 模式）与即时执行（yolo 模式）
- 查看编排运行状态与结果（世界图变更、生成的章节）

**内容**：
- 聊天区：消息气泡（用户/AI），支持流式输出（SSE 逐字）
- 编排控制条：模式切换（plan / yolo）、当前队列状态（空闲/运行中/等待确认）
- 计划卡片：策划结果预览（检索计划、待执行的行动），含「提交 / 丢弃」操作
- 结果摘要：编排完成后展示世界图变更数、新增章节、耗时

**交互**：
- 输入消息 → 发送 → 立即回执 → 聊天区流式更新 AI 回复
- 对话中 AI 触发编排时，控制条显示运行状态；plan 模式弹计划卡片等待用户确认
- 提交计划 → 继续执行；丢弃 → 终止本轮
- 编排完成 → 结果摘要可展开（跳世界图看变更 / 跳文件看章节）
- 运行中可离开页面，回来继续查看状态

**跳转**：结果中的世界图变更 → 世界图；章节 → 文件页对应章节（未实现自动打开，仅跳 #/files）；错误 → 调试页

---

### 5.6 调试（AI 运行过程可视化）

**功能**：
- 实时查看系统运行日志/事件流（SSE 长连接，自动滚动）
- 查看历史事件缓冲
- 按状态（start/end/error）/阶段/关键词过滤
- 清空缓冲

**内容**：
- 事件流面板（实时追加 + 自动滚动开关）
- 过滤栏：级别（debug/info/warn/error）、模块、关键词
- 缓冲统计（当前缓冲条数）

**交互**：
- 页面打开即连接实时流；断线自动重连
- 错误级别事件醒目高亮，可点击查看详情
- 「清空缓冲」二次确认
- 自动滚动默认开，用户上滚暂停（待实现）

**跳转**：无主动跳转（被动承接其他页的错误排查）

---

### 5.7 文件与章节编辑

**功能**：
- 浏览项目目录树（仅可编辑白名单文件：markdown 等）
- 查看/编辑章节 markdown（编排渲染的正文）
- 新建/删除/重命名文件
- 并发修改冲突检测（乐观锁）

**内容**：
- 左栏：目录树（展开/折叠、文件类型图标）
- 主区：编辑器（markdown 渲染 + 源码双模式）
- 顶部：文件路径、保存状态（未保存标记）

**交互**：
- 单击文件打开；多文件 Tab 切换
- 编辑后保存（Ctrl/Cmd+S），保存成功行内提示
- 冲突（其他进程改过）→ 提示重新加载/强制保存/忽略
- 新建文件：选择位置 + 命名；删除：二次确认
- 路径逃逸/非法后缀：统一阻止并提示

**跳转**：章节文件 ← 创作编排结果；从章节内实体名 → 搜索/实体详情（可选增强）

---

### 5.8 设置

**功能**：
- 模型配置：按用途（策划/角色/推理/渲染/默认）分别配置模型与 API Key
- 规则集管理：查看/编辑/重置系统提示规则集（策划、角色、渲染等）
- 项目配置：novel.json 编辑、.env 关键项（embedder 模型、调试开关）
- 应用配置：启动器、向量模型等全局项
- 运行环境检查（doctor）与版本/更新信息

**内容**：
- 页签或分区：模型 / 规则集 / 项目配置 / 应用 / 关于
- 规则集列表：名称、内容（编辑区）、重置按钮
- 环境检查结果表：各项状态（通过/警告/失败）+ 说明

**交互**：
- 模型配置表单：每用途一行（provider、model、API key），保存即生效（有校验）
- 规则集编辑：文本编辑 + 保存；重置还原模板（二次确认）
- doctor：一键运行，结果分色展示
- 更新：显示当前版本与最新版本，可触发更新（带进度）

**跳转**：无（设置中心）

## 6. 通用组件需求清单

设计师需为以下通用组件给出设计（本页不限定形态）：

| 组件 | 说明 |
|---|---|
| 顶部导航 | 页面切换 + 项目菜单 + 全局搜索入口 + storyTime 选择器 |
| storyTime 选择器 | 时间点列表/输入，全局共享同一选择 |
| 实体节点 | 3D 场景内节点（含类型色码、状态标记、选中态） |
| 实体列表 | 左侧栏列表（筛选/搜索/排序） |
| 详情抽屉 | 实体详情承载面板（含时间轴、关系表、可见性矩阵） |
| 消息气泡 | 聊天流式渲染（含角色/状态/工具调用摘要） |
| 计划卡片 | 编排计划确认/丢弃 |
| 事件流面板 | 调试实时流（级别色码、自动滚动） |
| 目录树 + 编辑器 | 文件浏览与 markdown 编辑 |
| 表单 | 通用表单（校验、错误定位） |
| 确认对话框 / Toast / 空态 / 骨架屏 | 全局反馈体系 |

## 7. 依赖与范围说明（给协作方）

- 本需求全部对应已就绪的 HTTP API；其中「编排控制（计划确认/队列状态）」依赖规划中的编排 HTTP 接口，开发与设计可并行推进
- 3D 场景仅描述功能与交互，不限定引擎/形态
- 本期为 Web 形态；后续打包桌面为交付形态切换，不影响本设计
